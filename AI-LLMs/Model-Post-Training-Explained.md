# 第八章读书笔记：模型后训练

阅读来源：[《深入理解 AI Agent》第八章](https://github.com/bojieli/ai-agent-book/blob/main/book/chapter8.md)。整理日期：2026-09-08。

模型已经掌握很多知识，却未必会按要求调用工具、纠正错误或在合适的时候结束任务。后训练通过新的学习信号调整参数，使已有能力更容易以期望的方式表现出来。理解它的关键，是分清“给模型看什么”“怎样判定好坏”和“根据什么更新参数”。

**1. 训练怎样改变模型**

语言模型根据前文，为下一个 token 分配概率。Token 是词元，可以是词、字或更小的片段；输出一段文字或工具调用，就是连续产生词元。

模型参数是内部参与计算的数值。损失函数衡量预测偏离训练目标的程度；梯度描述怎样改变参数会使损失变化；优化器根据梯度更新参数，学习率控制更新的步幅。

例如，参考答案的下一个词元是“查询”，模型只给它很低概率，监督训练就会推动相关参数，让类似情境下“查询”更容易出现。它不会把一条完整规则原样安装进脑中，而是在大量样本上改变条件概率。因此训练效果必须通过新任务检验。

普通推理只计算输出，不自动更新参数。让模型多想一次、增加上下文，属于推理时计算；调用训练程序修改参数，才是参数学习。

**2. 预训练、中期训练、SFT 和 RL 的区别**

| 环节 | 主要数据 | 学习目标 | 常见作用 |
| --- | --- | --- | --- |
| 预训练 | 大规模文本、代码等 | 预测后续词元 | 建立语言、知识和基础表征 |
| Mid-training：中期训练 | 目标领域、语言或能力语料 | 继续语言建模 | 补足专业知识及基础能力 |
| SFT：监督微调 | 输入与理想输出的示范 | 提高示范输出的概率 | 学习指令、格式与行为流程 |
| RL：强化学习 | 执行轨迹及奖励 | 提高期望回报 | 优化选择、探索和多步策略 |

表征是模型在内部组织信息的方式，例如把相关术语、物体或动作之间的关系编码进计算结果。中期训练不只是背诵事实，也可以为长文本、代码或特定语言建立更有用的表征。领域自适应预训练是在相关领域数据上继续训练的具体方式。[Don't Stop Pretraining](https://arxiv.org/abs/2004.10964)

这四个环节可以组合，但顺序不是绝对的。已有模型能理解任务并偶尔成功，就可能直接做 RL；连工具协议都无法稳定表达时，先用示范建立基本行为通常更有效。

资料缺失也不必总靠训练解决。RAG（检索增强生成）在回答前把相关材料找回来，适合频繁更新、需要引用和访问控制的事实。中期训练更适合补充广泛的领域理解；两者可以配合。

**3. SFT 从示范中学什么，为什么也可能过拟合**

SFT 的基本机制仍是预测下一个词元。差别在于数据通常组织成“指令、上下文 → 理想回答或动作”。常见实现只对助手输出计算损失，屏蔽问题和环境反馈；损失屏蔽的含义就是指定哪些位置提供训练目标。

示范既可以是最终回答，也可以包含完整工具交互。比如面对缺失字段，先向用户询问，拿到值后再调用接口。模型学习的不只是句式，还包括何时行动、需要多少证据、怎样响应错误。

过拟合是对训练样本的细节或捷径依赖过强，换一种表达、规则或环境后表现下降。泛化则是学到的能力能用于新样本；分布外测试（OOD）进一步改变训练时较少见的规则或条件，考察这种迁移。

“SFT 只会记忆、RL 天生泛化”过于绝对。SFT 的示范足够多样时同样可以学到可迁移规律，RL 的奖励存在漏洞时也会学到捷径。二者最根本的区别是优化目标，而不是一种只能背答案、另一种必然会思考。

LoRA（低秩适配）是降低参数更新开销的方法：冻结原始权重，用两个较小矩阵的乘积表示权重改变量。Rank（秩）控制这个改变量的表达规模。它可配合 SFT 或 RL，降低可训练参数和相关存储需求，但不保证保留全部旧能力，也不存在对所有任务都最优的秩和学习率。[LoRA 论文](https://arxiv.org/abs/2106.09685)

**4. 强化学习把行动与后果连接起来**

RL 的几个基础概念可以用下棋理解：

- 状态：当前局面及决策所需信息。
- 动作：可以选择的走法；动作空间是允许动作的集合。
- 策略：在某个状态下选择各动作的概率规则。
- 奖励：环境给出的反馈分数。
- 回报：一段时间内累计获得的奖励。

MDP（马尔可夫决策过程）用状态、动作、状态转移和奖励描述这种交互。马尔可夫性质要求状态包含足够信息，使未来变化只依赖当前状态与动作。Agent 常只能看到部分环境，所以实际还需要历史、记忆或状态估计。

价值函数估计“从这里继续走，未来通常能得到多少回报”。Q 函数进一步评价“在这里先选这个动作”的价值。贝尔曼关系把长期价值拆成当前奖励与下一状态的未来价值；折扣因子控制未来奖励在计算中占多大权重。

学习面临探索与利用的权衡：总选熟悉的做法，可能发现不了更好路径；一直尝试新做法，又可能消耗大量资源。语言模型已有的知识可以引导探索，但不能代替执行后的反馈。

**5. 一轮 Agent RL 实际做了什么**

Rollout 是按当前策略生成的一段执行轨迹；Episode 是从初始化到任务结束的一轮环境交互。实际训练常把完整 episode 或其中一段作为 rollout。

以修复代码为例，一轮训练通常包含：

1. 从同一个初始仓库生成多条轨迹，允许模型检索、编辑和测试。
2. 用独立验证器检查修复结果与必要约束，为轨迹评分。
3. 计算哪些选择比基准更好，得到优势（Advantage）。
4. 根据优势构造训练目标，计算梯度并更新参数，再用新策略采样。

信用分配指把最后的成败关联到中间行为。二十步以后失败，未必是最后一步错了，也可能在最初就选错了文件。结果奖励简单，但反馈稀疏；中间过程信号有助于定位，同时也更容易把错误的流程偏好写进奖励。

PPO（近端策略优化）常用价值模型估计基准，通过当前与采样时策略的概率比进行更新，并用裁剪抑制过大的变化。裁剪限制的是目标中的收益，不是策略变化的严格硬上限。[PPO 论文](https://arxiv.org/abs/1707.06347)

GRPO（组相对策略优化）比较同一问题的多条结果，以组内奖励计算相对优势，省去单独学习价值模型的开销。例如四条结果为“失败、失败、成功、成功”，组内就能形成区分；若全部同分，这项奖励就无法提供组内方向。[DeepSeekMath](https://arxiv.org/abs/2402.03300)

**6. 奖励来源、奖励时机和约束是不同问题**

RLVR 是使用可验证奖励的强化学习，例如用代码测试、数据库状态或答案校验给分。RLHF 是从人类反馈中学习，经典方式先根据偏好训练奖励模型，再优化策略。奖励模型是人类判断的近似，不是真理判定器。

DPO（直接偏好优化）则直接学习同一输入下的“偏好输出与不偏好输出”对，在标准形式中不需要另训显式奖励模型或边训练边做环境探索。它适合已经能收集高质量偏好数据的情况。[DPO 论文](https://arxiv.org/abs/2305.18290)

奖励何时给，是另一条轴：

| 方式 | 优点 | 代价 |
| --- | --- | --- |
| 结果奖励 | 容许多种解法，最终目标明确 | 很晚才知道好坏，探索可能低效 |
| 过程奖励 | 提供中间反馈，帮助信用分配 | 标注更难，可能误把固定步骤当必要条件 |
| 结果奖励加路径约束 | 保留解法自由，同时限制违规行为 | 约束仍需准确、可验证 |

例如“通过测试”可以作为结果奖励，但还要排除删除测试、编造输出等做法。奖励作弊指钻评分规则的漏洞；更隐蔽的偏离是只满足一个容易通过的代理指标，例如自行写一个很弱的检查，然后立即收尾。

KL 散度衡量两个概率分布的差异。在一些训练方法中，KL 约束用于抑制策略过快偏离参考模型；它有助于稳定，却不能修复错误奖励。生成式奖励模型还能给出诊断文字，诊断同样需要校准。

工具返回属于环境观察。做策略梯度训练时，应只优化模型生成的动作或词元，不能把环境输出误当作模型自己的行为。

**7. 为什么在轨数据重要**

On-policy（在轨）指轨迹由当前或足够接近当前的策略产生；Off-policy（离轨）指轨迹来自旧策略或其他策略。Online（在线）只表示数据在训练期间不断产生，因此在线采样也可能因模型版本落后而离轨。

这个区别影响“模型练习的状态是否是它现在真正会遇到的状态”。旧模型经常走错路，新模型已经不走那条路；继续大量使用旧轨迹，就可能优化偏离当前部署分布的问题。

重要性采样通过概率比给样本加权，补偿采样策略与目标策略的差异。但长序列中，许多小差异可能累积成极端权重，增加估计波动。策略版本越旧，修正通常越困难。

工程上还要检查训练端与采样端。即使加载相同权重，不同精度、计算内核或并行方式也可能算出不同概率；名义上的同步不能替代数值核对。这里追求的是训练信号与真实采样过程一致。

**8. 蒸馏让每次经历提供更多指导**

蒸馏让学生模型学习教师的答案、推导或预测分布。Prompt 蒸馏把长提示所引导的行为教给学生，目标是减少部署时的提示开销；推导蒸馏保留可获得、可验证的中间步骤，帮助学生学习解题过程。教师的错误也可能一起传入，因此数据筛选仍然必要。

在轨蒸馏先让学生自己生成轨迹，再让教师在这些状态上提供逐 token 指导。它解决了一个具体问题：只学习教师的顺利路径，学生部署时一旦偏离，就不知道怎样恢复；在学生实际遇到的错误状态上教学，指导更有针对性。[On-Policy Distillation](https://thinkingmachines.ai/blog/on-policy-distillation/)

稀疏结果奖励可能只说“这次失败”，逐 token 的教师分布则提供许多位置上的学习信号。代价是教师计算，而且教师必须能在这些状态上提供有效指导。

自蒸馏可以让同一模型承担教师与学生：教师看得到已验证答案或额外资料，学生只能看到原始问题。指导能力来自信息优势，不能把这些特权信息泄露到正式测试中；如果教师拿着答案也无法正确解释，自蒸馏就没有可靠的新信号。

**9. 训练方案应该由能力缺口决定**

| 观察到的问题 | 优先考虑的方向 |
| --- | --- |
| 缺最新事实或可追溯资料 | 检索与知识库 |
| 不理解目标语言、领域或基础结构 | 中期训练 |
| 会做但格式、流程或表达不稳定 | SFT |
| 能偶尔成功，但策略选择不可靠 | 有可靠奖励的 RL |
| 有更好的示范或教师指导 | 蒸馏、偏好优化 |
| 多次采样仍几乎全失败 | 先补能力、示范或简单课程，再考虑稀疏奖励 RL |

课程学习把任务从容易到困难安排，帮助模型逐步获得有效反馈。拒绝采样则从多个候选中筛出经验证的优质样本，可用于构造后续示范；筛选本身不等于完成参数更新。

训练必须同时检查新问题是否改善、旧能力是否保留。灾难性遗忘指学习新任务时明显破坏旧能力，可通过混合旧数据、控制更新等方式缓解。把“过早结束”改成“永远不敢结束”就是过度矫正，需要正常完成场景来约束。

评估集、训练集和经验提炼集应分开。训练损失下降只是说明更符合训练目标；只有新任务上的质量、可靠性和成本表现，才能说明这些更新是否值得使用。
